# VERITY TIME

Психологический хоррор-адвенчура от первого лица для ПК.
Вы — Друг №12. Тридцать два года назад вы сказали игрушке «я вернусь».
Она до сих пор ждёт.

> «Если оно помнит, боится и ждёт — то кто сказал, что оно не настоящее?»

## Как играть

| Действие | Клавиши |
|---|---|
| Движение | W A S D |
| Бег / присесть / прыжок | Shift / C или Ctrl / Пробел |
| Взаимодействие | E или ЛКМ (удерживать — для рычагов и вентилей) |
| Фонарик | F |
| Браслет «Друг» (сигнал, модуль тона) | B |
| Бросить предмет | ПКМ или G |
| Инвентарь / журнал / пауза | Tab / J / Esc |

Все клавиши переназначаются в «Настройки → Управление». Субтитры, их размер,
громкости по шинам, яркость, FOV, чувствительность, пресеты графики,
тени, текстуры, эффекты, масштаб рендера, режим экрана, разрешение и VSync —
там же. При первом запуске игра сама снижает пресет, если кадров меньше 40.

Сохранения: автосохранение на контрольных точках и три ручных слота
(в меню паузы).

## Структура игры

| Акт | Зона | Головоломки | Погоня / ключевая сцена |
|---|---|---|---|
| Пролог | Ворота | — | письмо, будка охраны |
| I «Добро пожаловать» | Холл | P1 щит, P2 код театра | первое появление на сцене |
| II «Мастерские» | Цеха | P3 конвейер, P4 краска, P5 реле браслета | Страж-7, Верити помогает |
| III «Что-то не так» | Отдел Гармонии | P6 терминал, P7 архив | плёнка КР-07, прятки |
| IV «Друг» | Игровая | P8 карусель, P9 театр теней | три вопроса, **погоня 1**: двери, засовы, свет, укрытия |
| V «Нижние уровни» | Старые цеха | P10 пар, P11 шкатулка | «Комната навсегда», **погоня 2**: маршруты, шум, камеры |
| VI «Сердцевина» | Очаг | P12 тройной замок | **погоня 3**: перестраивающийся коридор; 3 концовки |

19 секретов, документы и аудиозаписи в журнале (J). Тайная концовка требует
кассеты Тео и ни одной лжи Верити за всю игру.

### Верити

| Стадия | Облик | Где |
|---|---|---|
| 0–1 | глянцевый жёлтый шар-смайлик: два чёрных овальных глаза и тонкая улыбка | акты I–III, меню, статуя в холле |
| 2 | улыбка раскрывается в широкую пасть с двумя рядами зубов | акт IV |
| 3 | помятый грязный шар, впалые глаза-щели в синяках, рваная чёрная пасть с клыками | акт V |
| 4 | «настоящий»: очень высокое истощённое жёлтое существо с маленькой головой и той же ухмылкой | акт VI |

Шар прыгает при ходьбе и катится в погоне; высокая форма ходит и бегает
сгорбившись, пригибается под низким потолком и выбивает засовы руками.
Высокая форма вылеплена signed-distance-моделированием
(`src/models/sdf`, `src/models/verity`) и строится в фоновом потоке.

## Разработка

Three.js + TypeScript + Vite; оболочка ПК — Electron. Все модели, текстуры,
звуки, голоса и музыка генерируются процедурно во время работы — сторонних
ассетов нет.

```bash
npm install
npm run dev              # http://localhost:5173 — dev-сборка с отладкой (F1)
npm test                 # юнит-тесты логики (головоломки, сохранения, коллизии)
npm run typecheck
npm run build            # релизная web-сборка в dist/ (отладка вырезана)
npm run electron         # запуск ПК-версии
npm run package:win      # release/VERITY TIME-win32-x64 (+ .zip)
npm run package:linux    # release/VERITY TIME-linux-x64 (+ .zip)
```

### Отладка (только dev-сборка)

F1 — панель: телепорт по зонам и точкам, god mode, noclip, сброс головоломок
и триггеров, отрисовка коллизий и путей ИИ, перезагрузка уровня.
F3 — FPS, F5 — быстрое сохранение.
URL для тестов: `?zone=playland&spawn=stage&flags=k=v,...&items=a,b`,
`?modelview=carousel`, `?texdebug`.

### Автоматическая проверка

Безголовый Chromium (SwiftShader) проходит каждый акт через те же
интерактивные объекты, что и игрок, перематывая время:

```bash
npm run dev &
node tools/qa.mjs                    # все сценарии из tools/qa/*.mjs
node tools/qa.mjs playland core      # выборочно
node tools/multishot.mjs "zone=core&debug" shots/core a:0,0,-19,0 b:115,0,-31,0
```

Сценарии: research, playland, oldworks, core, ending_shutdown, ending_release,
retry_playland (поимка и повтор с контрольной точки), chain (переходы между
актами с инвентарём).

Электронная оболочка проверяется дымовым тестом:
`VT_SMOKE=out.png xvfb-run -a npx electron . --no-sandbox`.
